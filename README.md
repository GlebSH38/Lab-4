В данной папке собраны скрипты, демонстрирующие различные идиомы и продвинутые возможности языка Python (генераторы, декораторы, функции высшего порядка).

squaring.py (Функции высшего порядка)
Демонстрирует работу функции map(). Создает список чисел от 1 до 10, а затем применяет к нему лямбда-функцию для возведения каждого элемента в квадрат.

prime_numbers.py (Бесконечные генераторы)
Реализует бесконечный генератор простых чисел с помощью ключевого слова yield. Проверка простоты числа оптимизирована (перебор делителей до корня из числа, только нечетные). В main выводятся первые 10 простых чисел.

random_number_generator.py (Генераторы и случайные числа)
Создает бесконечный генератор случайных целых чисел в заданном диапазоне (от 20 до 50) с помощью модуля random. В main извлекаются первые 10 значений с использованием генератора списка.

cache_decorator.py (Мемоизация через декоратор)
Реализует паттерн «Мемоизация» (кеширование результатов). Декоратор memoize сохраняет результаты вызовов функции в словарь, что позволяет мгновенно вычислять числа Фибоначчи (пример fib(100)), избегая экспоненциального роста времени выполнения.

pipeline.py (Конвейер обработки данных)
Демонстрирует паттерн «Pipeline» (композиция функций). Функция pipe принимает набор функций и применяет их последовательно (слева направо) к входным данным с помощью reduce. В примере строка очищается от пробелов, переводится в верхний регистр и пробелы заменяются на подчеркивания.
